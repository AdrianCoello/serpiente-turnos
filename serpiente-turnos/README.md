# Serpiente por turnos

Juego de serpiente desarrollado con Vite, React y TypeScript.

## Características

- Tablero de 8 filas y 8 columnas.
- Serpiente inicial de tres segmentos.
- Movimiento mediante las flechas del teclado.
- Un movimiento por cada pulsación.
- Comida ubicada en una celda libre.
- Crecimiento de la serpiente al comer.
- Detección de colisiones con el borde y con el cuerpo.
- Señal visual cuando termina el juego.

## Requisitos

- Node.js
- npm

## Instalación

Clonar el repositorio e instalar las dependencias:

```bash
npm install
```

## Ejecutar el proyecto

```bash
npm run dev
```

Después, abrir en el navegador la dirección indicada por Vite.

## Construir para producción

```bash
npm run build
```

## Controles

1. Hacer clic sobre el área del juego.
2. Utilizar las flechas del teclado para mover la serpiente.
3. Cada pulsación representa un turno.
